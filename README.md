# Erannorth Reborn 简体中文汉化包

非官方社区汉化（简体中文），**解压即可使用**。覆盖界面、卡牌、敌人、专长、
地点、故事、游戏模式的文本，并为中文卡牌名附带全套卡面图。

## 下载

到 [Releases](../../releases) 页下载最新 `ErannorthReborn-Chinese-*.zip`。

## 安装

1. Steam 中右键游戏 → 管理 → 浏览本地文件，打开游戏根目录
   （形如 `...\Steam\steamapps\common\Erannorth Reborn`）。
2. 把压缩包里的 **`Erannorth Reborn_Data`** 文件夹整个复制进游戏根目录，
   提示覆盖时选"是"。存档不受影响。
3. 启动游戏即自动生效。

可选：游戏内 Mod Manager 里关闭 "Vanilla GameModes" 开关，
汉化版游戏模式（休闲/普通/钢铁人等）即可生效。

## 卸载 / 还原

Steam 右键游戏 → 属性 → 已安装文件 → **验证文件完整性**，
自动恢复全部原版文件。或手动删除
`Erannorth Reborn_Data\StreamingAssets\Content\Mods\Chinese Localization`
后再验证完整性。

## 汉化范围

| 部分 | 状态 |
|---|---|
| 界面 UI（含设置、图鉴、卡牌编辑器） | ✅ 全部 |
| 卡牌名 / 敌人名 / 专长名 / 地点名（含 2200+ 张卡面图） | ✅ 全部 |
| 故事（Tales）88 篇 | ✅ 全部 |
| 游戏模式描述 10 个 | ✅（配合关闭 Vanilla GameModes 开关） |
| 增益/减益（Buff）名称、符文词（Rune Words） | 保留英文（游戏逻辑标识/玩法设计） |

## 注意

- 基于当前 Steam 版制作；游戏更新后若文本错乱，先"验证文件完整性"还原，
  再等汉化更新。
- 仅供学习交流，勿用于商业用途；请支持正版。
